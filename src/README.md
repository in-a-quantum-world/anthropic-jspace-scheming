# src

Analysis and pipeline scripts. `metrics_lib.py` holds the shared metric definitions, `regenerate_tables.py` rebuilds every reported table from `results/`, `item_log.py` writes the item-level inclusion log, `week1_depth_sweep.py` is the read-depth analysis, `fit_lens_5070.py` fits a Jacobian lens on a single consumer GPU, `run_sandbag_local.py` runs the sandbagging evaluation locally on a small model, and the `build_*.py` scripts construct the question banks. The Colab notebooks live in `notebooks/`.
